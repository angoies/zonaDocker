    Resumen clase repaso¶

    1. Directorio local¶

    Tener preparado carpeta de proyecto en local y que funcione

    • .env
    • compose.yml
    • carpeta letsencript, etc.

    Apartados de Zona Docker

    2. Crear EC2 en AWS¶

    • Crear una plantilla de lanzamiento
    • con vockey.pem

    • y script de instalación (ojo con usuario...)

      #!/bin/bash
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh
sudo groupadd docker
sudo usermod -aG docker admin

    • Crear instancia EC2 desde la plantilla

    • Esperar a que todo ok

    • Conexión ssh (ver intrucciones, pero ±)

      ssh -i vockey.pem admin@IP_EC2

    • Probar instalación de docker

    3. Transferir carpeta del proyecto¶

    lo más sencillo es con el comando scp (ojo con : final)

    scp -i vockey.pem \
    -r carpeta_proyecto \
    admin@IP_EC2:

    4. Variables de entorno¶

    No olvide incluir las variables del fichero .env:

    set -a
source .env
set +a
# comprobar
echo $DOMAIN

    5. Actualizar IP del dominio desde EC2¶

    Compruebe que tiene las variables de entorno necesarias y sus nombres.

    Si está usando freemyip:

    curl \
 "https://freemyip.com/update?token=${FREEMYIP_TOKEN}&domain=${DOMAIN}&verbose=yes"

    O si usa duckdns:

    curl \
 "https://www.duckdns.org/update?token=${TOKEN}&domains=${DOMAIN}&verbose=true"

    Y compruebe la actualización de la IP en el dominio

    dig +short ${DOMAIN}

    Apartados zona Docker

    • DNS en AWS

    6. Lanzar traefik¶

    Si todo lo anterior es correcto entondes lanzar el compose poco a poco:

    docker compose up -d traefik
# comprobar logs y docker ps
docker compose up -d whoami
# comprobar logs y docker ps

    Y puede hacer una primera prueba en local desde la EC2:

    curl -Lk whoami.${DOMAIN}

    7. Probar desde host (su equipo)¶

    Antes de probar COMPRUEBE:

    • que en el fichero /etc/hostsno tiene definido el dominio.
    • que tiene definida la variable de entorno DOMAIN
    curl -Lk whoami.${DOMAIN}
firefox --private-window whoami.${DOMAIN}
